# FluxFX 像素特效提示词

复制下面的模板，填入方括号。尺寸和位置用逻辑像素，时间用秒。明确哪一拍最醒目，以及退场最后能看到什么。

```text
$fluxfx-vfx 用 FluxFX 制作「[名称]」。
用途 [攻击 / 增益 / 治疗 / 位移 / 环境]，画布 [宽×高]，时长 [秒]，锚点 [x, y]。
[起点、落点、方向、目标位置，以及特效是否跟随角色]。

【动作与节拍】
- [起止时间] 蓄力。描述第一眼可辨的形状、运动方向和角色动作。
- [时刻] 释放或命中。描述最亮的物体、轮廓、厚度和目标反馈。
- [起止时间] 展开。描述远近层、粒子的路径、速度差和受力后的反应。
- [起止时间] 收尾。说明哪些元素先熄、哪些最后留下，以及它们如何散去。
多段动作可以依次添加。标出事件准确时刻，区分出手与命中。

【像素美术硬要求】
- 全程按原生逻辑网格绘制。主体、粒子、烟尘、余光和淡出阶段都使用
  清楚的台阶轮廓、连贯像素簇和离散色阶。预览用整数倍最近邻放大。
- 主体剪影为 [形状和边缘特征]。主要材质使用 [暗部 / 主色 / 受光边]。
  峰值首先读清 [主焦点]，把最亮的颜色留给 [部位和时刻]。
- 若有烟、尘或雾，用错落的不对称像素簇构成体积，内部用少量不规则
  明暗块塑形。扩张靠簇形长大和错位，消散靠边缘掉块、缺口扩大、
  残点减少。看到重复的圆泡、同心色块或靠柔光撑成的烟团就重画。
- 后层画 [远侧元素]，前层画 [主体和近侧元素]。
  把加法光照留给 [能量核心、亮边或热点]，独立输出。

【验证与交付】
- 接入工作台，核对 [坐标、事件名和时刻]，验证时间轴可以回拖。
- 给出 [蓄力、峰值、反应、收尾] 的准确预览时点。
  在 1× 和 2× 或 3× 整数倍下查看峰值与收尾，关闭光照再检查剪影。
- [如需导出] 以 [FPS、种子] 导出前层、后层、光照精灵图与 JSON。
```

## 烟尘描述示例

> 落点先推开一条贴地棕灰尘浪，大团烟簇向上卷起，小簇被气流向右带走。用深棕灰、灰褐、暖灰三阶组成不对称台阶轮廓。亮面向着火光，边缘留出缺口。收尾先让外沿掉块，再让最后几粒暗点熄灭。查看原尺寸和 3× 的收尾帧，并关闭加法光照检查烟体剪影。

给主要材质一个可辨的形状和运动过程，例如岩龙用断面鳞片，风翼用带缺口的长像素带，火砾抛起后弹落。法阵、星轨和冲击环可以保留有设计意义的圆形，描边与亮点依然遵循逻辑像素网格。
